## What's here

Static site — plain HTML, one stylesheet, one small script. No framework, no build step, no database.

```
index.html          Home — hero, capability strip, services, why-us, packaged solutions, process, projects, industries, FAQ, CTA
about.html          About Us — who we are, principles, how an engagement runs
services.html       Services — 6 detailed service lines + engagement models + FAQ
solutions.html      Solutions — 6 packaged solutions + sector focus + what's always included
projects.html       Projects — 4 case summaries + how we present work
industries.html     Industries — 6 sectors + cross-industry section + FAQ
contact.html        Contact Us — enquiry form, contact details, map, "before you send"
404.html            Not found
sitemap.xml         Search engines
robots.txt          Allows crawling, points at sitemap
favicon.svg         Gradient "S" mark
assets/css/site.css Stylesheet (design tokens + components)
assets/js/site.js   Header state, mobile menu, scroll reveals, counters, form handling
assets/img/*.webp   Photography — Pexels licence (free for commercial use), re-encoded to WebP
assets/img/*.jpg    Same images in JPEG for older browser fallback / social sharing
```

Generated by `../../build_sresak_site.py` (edit that, re-run it, then redeploy — don't hand-edit the HTML).

## Before going live — replace the placeholders

Search the generated HTML for `[待确认]`:

| Where | What is needed |
|---|---|
| Header/footer + `contact.html` | Business phone number |
| `contact.html` | Business hours |
| `contact.html` | Formspree form id — create a form at formspree.io, then replace `https://formspree.io/f/[待确认]` (the form shows a friendly notice until then) |
| `about.html` | Team names, roles, photos (only with each person's consent) |
| `about.html` | Certifications, vendor partnerships, insurances — list only what is current |
| `projects.html` | Client names / logos if permission is granted |

Content review points: the four project summaries on `projects.html` describe
representative engagements (client names withheld). Replace with real, permissioned
case studies before this is used in a pitch.

## Deploy

Hosted on GitHub Pages (`EthanX0904/sresaksoftware.com`), DNS on Cloudflare, domain at GoDaddy.

```bash
cd /root/deploy/sresaksoftware.com
git add -A && git commit -m "describe the change" && git push
```

Pages rebuilds automatically (~1 minute). DNS: 4× A records to 185.199.108–111.153,
`www` CNAME to `ethanx0904.github.io`, both DNS-only (grey cloud) so GitHub can issue the certificate.
